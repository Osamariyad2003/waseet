# Waseet

AI-mediated escrow on PayPal. A buyer funds a deal, the platform holds the money, an AI verifies the seller's deliverable against agreed criteria and auto-releases payment on a confident pass — or routes the deal to a human-reviewed dispute.

Prototype for the PayPal AI Hackathon. Everything runs against the **PayPal sandbox** — no real money.

Setup and run instructions land in Phase 6; see `docs/` for the full brief.
